## 612 (Budget archive Test/budget_archive_test/budgetarchivetest)
8 Dec 2021
Loosely inspired by Blue Archive, this game is about recruiting students and fight against (apparitions of?) teachers in an abandoned school. You can upgrade students with textbooks and randomish artifacts obtained from combats. One of the most complex games among all these, with a real time tactical combat system and a good number of hand-crafted stages. Originally named Budget archive, with the test appended when I go into development versions. Development went on and off until ~Aug 2023, adding fancy new features such as infrastructure. I think this is also the first project where I used Add Source Directly to a significant degree.

Trivia: early versions use package name newproject2 leading to collisions before change.

More random rant (7 Apr 2022): "Started development when stack cup competition, making the combat view with icons when health check, making the health bar in combat view works on a Saturday in Shek Mun"

## 617 (Test/RenderingEngine/boardgame)
9 Oct 2022
I forgot what board game referred to. This project contains the prototypical rendering (actually layout) engine I use in many upcoming projects. I supply the engine with a list of entities with their x, y positions, and the engine will adjust the TranslateX and TranslateY as to make images (typically the default android icon) appear at the specified position in the layout. This opens lots of freedom in designing graphical UI.
