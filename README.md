# sketchware-projects-archive
Collection of sketchware projects I have (mostly simple Android games). More specifically, the .sketchware/mysc folders.

# List of projects
Missing numbers are probably projects I deleted at some point (?).


Format: folder number (App name/project name/package name when different from com.my.lowercase_project_name)

## 605 (Button tapping/NewProject5)

## 606 (BorkBrowser/NewProject6)

## 607 (TextEditor/NewProject7)
A simple text editor for opening .txt on my phone. It kind of sucks but I still use it very occasionally for saving .txt files. (Honestly I should get a new one)

## 608 (Yuen Fun/NewProject8)
Calculates the "Yuen Fun" value for a date using ~~divinely revealed~~ formula. Also support sharing the values as text.

## 609 (project 2/OldProject3/newproject3)
The name references the original project, an idle game written in app inventor. Just like its predecessor, project 2 is a random themeless idle game where you buy buttons that make money so that you can buy more buttons. It is the first project where I figured out how multiple screens work.

## 610 (Thinking face🤔/BungorProject3)
A roguelike (in some sense) game where you explore rooms and survive as long as possible. You get the eponymous thinking faces as reward for survival which you can use for permanent upgrades. This app is a factor for deciding my Discord username, and by extension this github username. Also inspired a friend to write a similar game about exploring an abandoned school with humanoids.

## 611 (Music game test/NewProject333)
A purported music game where you click notes coming in over 4 lanes with absolutely no relation with the background music. Even starting the game is hard because the start game button moves around quickly. There is also a special screen where I figured out how Maps and List Maps work.

## 612 (Budget archive Test/budget_archive_test/budgetarchivetest)
Loosely inspired by Blue Archive, this game is about recruiting students and fight against (apparitions of?) teachers in an abandoned school. You can upgrade students with textbooks and randomish artifacts obtained from combats. One of the most complex games among all these, with a real time tactical combat system and a good number of hand-crafted stages. Originally named Budget archive, with the test appended when I go into development versions. I think this is also the first project where I used Add Source Directly to a significant degree.

## 614 (Map generator 2/NewProject788)
Generates a random ASCII-art terrain map by adding noises over different scales. The rendering may fail on some device because of the font width though.

## 615 (Idle world/AncientProject)
Inspired by SimCity games, this game is about producing (vaguely) minecraft-themed items, fulfilling the orders on the marketplace and expand your factory with the money. The idle in the name means the game runs in real time, with the early items taking minutes to produce.

## 616 (Prime number output/PrimeProject2/primeproject)
A tool for factorizing integers up to ~2^63 using wheel factorization. Can also output all prime numbers less than an upper limit.

## 617 (Test/RenderingEngine/boardgame)
I forgot what board game referred to. This project contains the prototypical rendering (actually layout) engine I use in many upcoming projects. I supply the engine with a list of entities with their x, y positions, and the engine will adjust the TranslateX and TranslateY as to make images (typically the default android icon) appear at the specified position in the layout. This opens lots of freedom in designing graphical UI.

## 625 (Jumping pieces/JumpingPiece)
A game where two players alternatively move their pieces on a 1xN grid by having their piece jump over another piece, and aims to avoid having no moves available. The app solves the game with backward induction and produces a complete table of moves and how good they are.

## 628 (Dice roll simulator/NewProject3)
